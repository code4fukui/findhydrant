# findhydrant

5つ星オープンデータを活用して、日本国内の消火栓やその他の緊急用水利を検索するウェブアプリです。

## デモ

**ライブアプリ: https://github.com/code4fukui/findhydrant

インターフェースには、さまざまな水利がアイコンで地図上に表示されます。「前へ」と「次へ」ボタンを使って、現在地から近い順に場所をナビゲートできます。

## 機能

- **さまざまな水利の検索:** 消火栓だけでなく、防火水槽、プール、その他の指定水利も検索できます。
- **インタラクティブな地図:** Leafletと国土地理院（GSI）のタイルを活用したインタラクティブな地図上に場所を表示します。
- **近い順に表示:** 現在地からの距離に基づいて、自動的に水利を検索し近い順に並べ替えます。
- **簡単なナビゲーション:** 「前へ」と「次へ」ボタンを使って、並べ替えられた場所のリストを順に確認できます。
- **詳細情報:** アイコンをクリックすると、分類、住所、担当部署、管径などの詳細情報が表示されます。
- **多言語対応:** UIはブラウザの言語設定に自動的に適応します（日本語、英語などに対応）。
- **Geo3x3連携:** 現在の地図の中心位置を[Geo3x3](https://geo3x3.com/)コードとして表示します。

## 必須環境

最適な体験を得るには、位置情報サービスが有効になっているモダンなウェブブラウザが必要です。

## 使い方

1. **アプリを開く:** [デモページ](https://code4fukui.github.io/findhydrant/)にアクセスします。
2. **位置情報へのアクセスを許可:** 最寄りの水利を検索するため、アプリが現在地の取得をリクエストします。
3. **結果をナビゲート:** 「前へ」と「次へ」ボタンを使って、距離順に並んだ近隣の場所を閲覧します。地図は選択された場所に自動で移動します。
4. **詳細を表示:** 地図上のアイコンをクリックすると、その水利に関する詳細情報がポップアップで表示されます。

## データと技術

- **データソース:** すべてのデータは、**オープンデータプラットフォーム（ODP）のSPARQLエンドポイント**からリアルタイムでクエリされます。
- **地図ライブラリ:** [Leaflet](https://leafletjs.com/)と[国土地理院（GSI）](https://maps.gsi.go.jp/development/ichiran.html)の地図タイルを使用しています。
- **ジオコーディング:** 地図の座標表現に[Geo3x3](https://geo3x3.com/)を使用しています。
- **コア技術:** バニラHTML、CSS、JavaScript（ESモジュール）で構築されています。
